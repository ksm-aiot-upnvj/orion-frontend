Profil Organisasi

Pusat Kolaborasi Riset & Rekayasa IoT Mahasiswa

KSM AIoT (Kelompok Studi Mahasiswa Artificial Intelligence of Things) didirikan untuk menjembatani teori komputasi akademis dengan penerapan rekayasa perangkat keras dan otomatisasi cerdas berstandar industri.

Riset Terapan Perangkat Keras

Eksplorasi sensor terdistribusi, komunikasi LoRaWAN & MQTT, serta integrasi mikrokontroler berdaya rendah untuk monitoring lingkungan presisi.

Kecerdasan Buatan Terintegrasi

Penerapan Computer Vision pada Edge Device, model Machine Learning analitik, dan arsitektur RAG untuk pengolahan repositori data kampus.

Tata Kelola & Otomasi Kampus

Pengembangan sistem informasi terpadu, otomatisasi bot administrasi Discord, serta standardisasi arsip dan inventaris laboratorium.

Kurikulum & Peminatan

3 Bidang Riset & Pengembangan

Anggota KSM AIoT dibekali kurikulum terstruktur yang dipraktikkan langsung dalam proyek nyata.

Hardware & Embedded

Perancangan sirkuit mikrokontroler (ESP32, STM32, Arduino), akuisisi data sensor real-time, protokol transmisi MQTT, LoRaWAN, dan FreeRTOS.

#ESP32 #SensorArray #MQTT #FreeRTOS

AI & Machine Learning

Implementasi Computer Vision di Edge Computing, model klasifikasi data sensor, RAG semantic search dengan pgvector, dan analitik cerdas.

#PyTorch #YOLOv8 #LangChain #RAG

Web & Cloud Systems

Pengembangan platform manajemen terpadu (FastAPI, PostgreSQL, Vue.js), integrasi REST API, otomatisasi bot administrasi, dan kontainerisasi Docker.

#FastAPI #PostgreSQL #VueJS #Docker
