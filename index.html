Tentang KSM AIoT

Eksplorasi Riset & Pengembangan Berbasis Kolaborasi

KSM AIoT dirancang sebagai ekosistem pembelajaran terbuka tempat mahasiswa mengasah keterampilan praktis hardware IoT, kecerdasan buatan, hingga web development.

Hardware & Embedded

Perancangan sirkuit mikrokontroler (ESP32, STM32, Arduino), pemrosesan sinyal sensor, protokol komunikasi MQTT, LoRaWAN, dan IoT Telemetry.

#ESP32 #SensorArray #MQTT #FreeRTOS

AI & Machine Learning

Implementasi Computer Vision di Edge Devices, Natural Language Processing, RAG Semantic Search (pgvector), dan model machine learning terapan.

#PyTorch #YOLOv8 #LangChain #RAG

Web & Cloud Systems

Pengembangan Management Platform (Vue.js, FastAPI, PostgreSQL), RESTful API, bot otomatisasi Discord (Nexo Bot), dan infrastruktur Docker.

#VueJS #FastAPI #PostgreSQL #Docker
